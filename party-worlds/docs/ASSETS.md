# Asset and licence record

Everything visible and audible in the game is generated by code in this repository at run time. There are no model, audio or video files, and the only image files are the home-screen icons, which are drawn by a script in this repository.

| Asset | Source | Licence | Notes |
|---|---|---|---|
| Characters (grown-ups, kids, dogs, cats, and the bear, fox, rabbit, frog, robot, alien and masked wrestler) | `src/characters/` | Original, this project | Invented cast; no real person, pet, brand or existing game character is depicted |
| Backyard After Dark world and the karts | `src/worlds/backyard/` | Original, this project | Geometry from code; lawn, slab, soil, wood, tennis-ball and sky textures drawn to canvases at load |
| Birthday Continental props, textures and backdrop | `src/worlds/birthday/` | Original, this project | Patterns are drawn to canvases at load |
| Sound effects and music | `src/audio/` | Original, this project | Synthesised with Web Audio. Lobby and race music share one four-chord loop (Am, F, C, G) under an original lead line; Courier keeps an original pentatonic phrase |
| Interface icons | `src/ui/icons.ts` | Original, this project | Hand-written SVG paths |
| App icon and home-screen icons | `public/icon.svg`; `public/icon-180.png`, `icon-192.png`, `icon-512.png` | Original, this project | The SVG is hand-written; `node dev/make-icons.mjs` renders the PNGs from it. No text, so no typeface is embedded |
| Typefaces: Barlow and Barlow Condensed | npm packages `@fontsource/barlow`, `@fontsource/barlow-condensed` | SIL Open Font License 1.1 | Bundled as woff2 only (Latin subset: Barlow 500 and 600; Barlow Condensed 600, 700 and 800 italic) |

Licences are as stated by each package; re-check `node_modules/<package>/LICENSE` before a commercial release.

## Names

"BounceBack Party Worlds", "Backyard Dash", "Backyard After Dark", "Catapult Courier", "The Birthday Continental" and the character names are working names. None has been searched against trademarks or app-store listings.
